# Кристина, Питер тебе к лицу

Одностраничная кинематографичная открытка: тёмная вода, силуэт Петербурга,
ветер, парус. Никаких стоковых фото — вся атмосфера рисуется процедурно
на Canvas 2D, парус — SVG-силуэт.

## Стек

- React 19 + TypeScript + Vite
- Canvas 2D — небо, город, вода, туман, отражения (одна сцена на всю страницу)
- SVG — парусник с отражением и кильватерным следом
- CSS Modules — типографика и появления текста
- Web Audio — процедурный ветер/вода/город, только по кнопке

Вес: ~81 КБ gzip JS + 3 КБ gzip CSS, без картинок и шрифтов в бандле
(шрифты приходят с Google Fonts).

## Команды

```bash
npm install       # зависимости
npm run dev       # локальная разработка
npm run build     # проверка типов + сборка в dist/
npm run preview   # посмотреть собранную версию локально (порт 4173)
```

## Деплой на Render.com (бесплатно)

1. Залей проект в GitHub-репозиторий.
2. В Render: **New → Static Site**, подключи репозиторий.
3. Render прочитает `render.yaml` — или вручную укажи:
   - Build Command: `npm ci && npm run build`
   - Publish Path: `dist`
   - Node: 24 (через `.nvmrc`)
4. Deploy. Сайт будет на `https://<имя-сервиса>.onrender.com`.

Бесплатный тариф: статический сайт не таймаутится, засыпает только при простое
и просыпается за несколько секунд. Push в ветку → автодеплой
(`autoDeployTrigger: commit` в `render.yaml`).

`public/_headers` задаёт кеширование: хешированные ассеты — на год,
`index.html` — без кеша.

### После первого деплоя

В `index.html` OG-картинка указана относительным путём (`/og.png`).
Большинство мессенджеров подставляют домен сами, но если превью не появилось —
замени на абсолютный URL:

```html
<meta property="og:image" content="https://<твой-домен>.onrender.com/og.png" />
```

## Где что менять

- **Тексты** — `src/content/site.ts`. Никаких правок в компонентах не нужно.
- **Высоты сцен** (сколько экранов длится каждая) — `sceneScreens`
  в том же файле.
- **Атмосфера** (палитра, плотность тумана, число огней) — `LOOKS`
  в `src/lib/atmosphere.ts`: один ключевой кадр на сцену.
- **Парусник** — `src/components/Sailboat.tsx`.
- **Звук** — `src/lib/ambience.ts` (громкость слоёв, частоты фильтров).

## Доступность и производительность

- `prefers-reduced-motion: reduce` — анимации выключаются, весь текст виден сразу.
- Сценарий читается с клавиатуры и экранным дизайнером: `main > section[aria-label]`,
  скрытый `h1` с полным названием.
- Рендер останавливается в фоновой вкладке, на слабых устройствах
  автоматически упрощается (меньше частиц, бликов и отражений).
- Горизонтального скролла нет ни на 320px, ни на десктопе; используются
  `svh` и safe-area под мобильные браузеры.

## Ограничения по содержанию

Персонализация — только через имя, Петербург и парусный спорт.
Фотографий Кристины на сайте нет и не должно быть: придумывать внешность
и выдавать сгенерированный портрет за реальный — нельзя.
